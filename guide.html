給 Buege 與言熙看的部落格說明書。最後更新：2026-10-11。

一、現在怎麼發文 目前使用中

文章其實是一個個文字檔，放在專案的 _posts 資料夾，推上 GitHub 後約 1～2 分鐘就會出現在網站上。目前由 Buege 在 Claude 的協助下發布，言熙還沒有自己的發文管道。

檔案格式：

  • 檔名：年-月-日-英文名稱.md，例如 2026-10-15-first-trip.md（用英文是為了讓網址不要變成一串亂碼）。
  • 檔案最上面要有一塊設定，用兩條 --- 夾起來： 
    ---
title: "文章標題"
author: 言熙
---
這裡開始寫內文
  • 標題含有 !、: 這類符號時，標題要用雙引號包起來，否則網站會建置失敗。
  • author 寫 Buege 或 言熙，會顯示在文章日期旁邊。
  • 內文按一次 Enter 就會換行；空一行會多一個段落間距。

這樣對不熟程式的人不友善，所以我們打算改用下面的網頁後台。

二、打算改成什麼 規劃中，尚未啟用

使用一個免費的網頁後台，叫 Pages CMS。用 GitHub 帳號登入後，看到的是「文章列表＋填寫表單」：填標題、選作者、寫內文，按儲存就發布。不用碰檔案、不用打格式。

項目說明
費用免費
誰能用Buege 與言熙，手機、電腦都可以
文章存放處仍然在我們自己的 GitHub 專案裡，不綁任何平台，要搬走隨時可以
發布速度按儲存後約 1～2 分鐘上線

三、要啟用，需要先做這三件事

  1. 言熙：註冊一個免費的 GitHub 帳號（github.com，用信箱註冊，一分鐘）。完成後把帳號名稱告訴 Buege。
  2. Buege：把言熙加為專案的「協作者」。做法有兩種：叫 Claude 幫忙發邀請；或自己到 GitHub 專案 buege1216/buege.net → Settings → Collaborators → Add people。
  3. 言熙：到信箱（或 GitHub 通知）按「接受邀請」，沒接受就看不到、也改不了專案。
  4. Claude：在專案加入後台設定檔（定義表單長什麼樣、有哪些欄位），之後兩人就可以用後台發文。

四、啟用之後怎麼發文

  1. 用瀏覽器開 Pages CMS，按「用 GitHub 登入」，選 buege.net 專案。
  2. 按「新增文章」，填標題、選作者、寫內文。
  3. 按儲存。約 1～2 分鐘後 buege.net 就會出現。

以上是依規劃寫的，Pages CMS 實際的畫面與按鈕名稱，啟用那天再照實際情況更新本頁。

五、常見問題

  • 發出去了但網站沒變？先等 2 分鐘，再按 Ctrl+F5 強制重新整理。
  • 想修改或刪除舊文章？啟用後台後可以直接在後台改；目前請告訴 Claude。
  • 想放圖片？目前還沒設定圖片流程，有需要請告訴 Claude，會一併規劃進後台。
  • 聯絡信箱：hello@buege.net（轉寄到我們的信箱）。
